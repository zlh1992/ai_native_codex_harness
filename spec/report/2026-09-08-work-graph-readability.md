## 背景与证据

老板工作图的依赖图卡片被 CSS 固定为 144px 高，并把任务标题限制为两行。较长中文任务标题因此在卡片中被截断，状态与截止信息也可能被推出可见区域。依赖图、状态列表和事件记录按钮缺少当前选中态及用途说明；缩放按钮在非依赖图视图仍可操作，但不会立即产生可见效果。

## 目标与非目标

### 目标

- 缩小任务标题字号并取消两行截断，让任务信息可读。
- 为依赖图卡片和多行状态列表提供明确的纵向滚动能力；工作图区在节点较多时可上下滚动。
- 显示当前视图选中态、简短用途说明，并仅在依赖图中启用缩放。
- 保持点击任一任务节点打开同一个任务详情抽屉的行为。

### 非目标

- 不改变 DAG、任务状态、审核、调度或 API。
- 不重新设计节点布局算法或引入第三方图形库。
- 不改变老板与员工权限。

## 约束与风险

- 保持 `WFG-001` 至 `WFG-003` 及 E2E-015，不削弱现有工作图发布门禁。
- 固定尺寸依赖图节点必须与 JavaScript 布局步长和连线中心同步，避免节点重叠或箭头错位。
- 内部滚动不能阻断任务按钮的点击和键盘聚焦；列表与移动端仍需保持可读。

## 实施计划

1. 调整工作图节点尺寸、标题排版、滚动区域和滚动条样式，并同步布局常量。
2. 为三种视图增加选中态、用途说明与缩放按钮状态。
3. 增加前端静态契约测试，更新长期架构与发布契约说明。
4. 运行相关测试、完整 `npm run gate`、`git diff --check` 和 Markdown 相对链接检查；确认运行中服务已提供最新静态资源。

## 实际改动

- `public/work-graph.js` 用显式节点宽高、列距和行距生成布局，节点高度从 144px 调整为 176px，并让箭头锚点跟随节点中心；同层多节点的纵向步长从 168px 调整为 200px。
- 工作图任务标题使用独立 15px 样式，不再进行两行截断。固定高度依赖图节点可内部纵向滚动；依赖图看板和状态列表都有最大视口高度与稳定滚动条。
- 三个视图按钮显示当前选中态和对应说明；缩放按钮在状态列表、事件记录中禁用。依赖图与状态列表继续复用同一节点点击和详情抽屉。
- `test/frontend.test.mjs` 固定标题、滚动、选中态、缩放范围及布局不重叠契约；操作文档、工作图架构和发布契约同步更新。
- 无 API、数据或权限偏差。运行中服务对非指纹静态资源采用 `no-cache` 并已实时提供新脚本，因此没有为纯静态修改中断本地服务或重建公网隧道。由于当前浏览器停留在登录页且未使用生产凭据自动登录，未声明带真实账号的截图验收；通过实时静态资源读取、专项测试和完整门禁验证发布内容。
