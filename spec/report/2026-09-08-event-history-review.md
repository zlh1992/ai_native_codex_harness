## 背景与证据

项目事件数组在刷新后清空，但订阅沿用 sessionStorage 游标，造成历史缺失；数组另有限制最近 100 条。native item 会覆盖同 callId 的真实工具名。

## 目标与非目标

- 目标：重放全部当前授权项目事件，按 id 去重倒序，不截掉旧事件；保留工具真实名称。
- 非目标：本轮 review 不新增 Luna 摘要后台服务或模型记忆 CRUD 工具。

## 约束与风险

遵循 DAT-006，不向事件加入工具原始输入输出。项目切换后忽略旧连接回调。历史较大时完整重放有内存成本，后续可增加分页展示。

## 实施计划

1. 新页面从零重放，当前连接依赖 EventSource 的 Last-Event-ID 恢复，按 id 合并。
2. 工具真实名称优先于原生类型标签。
3. 完整 gate、diff 和链接检查；保持正在执行的员工任务不中断。

## 实际改动

新页面从零重放数据库项目事件，按 id 去重排序，不截断历史；忽略已切换连接的回调。工具开始与完成保留真实名称，后续 native item 不再覆盖。正在运行的服务已直接提供最新静态脚本，未重启或打断员工任务。

## 数据、接口与安全影响

无数据库迁移、API 或 ACL 变化；不保存原始工具正文。回滚只恢复此次前端改动。

## 验证

- `npm run gate`：96/96 单元与集成、17/17 HTTP E2E 通过。
- `node --input-type=module` 行为检查：乱序送入 150 条项目事件，全部保留；重复 id 去重；旧连接回调忽略。
- `git diff --check`：通过。
- Node 相对 Markdown 链接检查：通过。
- `curl -fsS http://127.0.0.1:4310/work-graph.js`：确认线上脚本包含从零重放与排序实现。
- 生产只读查询运行状态和进度元数据；未读取凭据、修改账号或持久化任务正文。无临时账号或业务数据需要清理。

## 结论

事件历史和真实工具名修复通过验证；记忆能力、索引在线表述限制、Luna 摘要设计及长任务状态已完成 review。Luna 摘要服务未实现，不能将真实名称修复描述为 AI 摘要已上线。
